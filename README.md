# 🎮 Biblioteca Gaming con Streamlit y MongoDB

Aplicación para gestionar tu colección personal de videojuegos.

## 🚀 Cómo empezar
1. Clona este repositorio.
2. Crea tu entorno virtual: `python -m venv .venv`.
3. Instala las dependencias: `pip install -r requirements.txt`.
4. Configura tu archivo `.env` con tu URI de MongoDB (mira `.env.template`).
5. Ejecuta la app: `streamlit run main.py`.
